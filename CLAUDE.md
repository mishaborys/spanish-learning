# Spanish Learning App — інструкції для AI

## Що це за проект

Next.js 16 / React 19 / TypeScript застосунок для вивчення іспанської мови.
Є два основних типи контенту, якими потрібно керувати:

1. **Теми** (Topics) — словниковий запас + граматика, зберігаються в базі даних Neon PostgreSQL
2. **Домашні завдання** (Homework) — інтерактивні вправи, зберігаються в JSON-файлах на диску

## Технічний стек

- **Framework**: Next.js 16 (App Router)
- **БД**: Neon PostgreSQL через `@neondatabase/serverless`
- **Стилі**: Tailwind CSS v4
- **UI компоненти**: shadcn/ui
- **Іконки**: lucide-react
- **Скрипти**: tsx

## Як додати нову тему (Topic)

### Крок 1 — створити JSON-файл

Створи файл `data/topics/<slug>.json` за таким шаблоном:

```json
{
  "title": "Назва теми українською",
  "slug": "unique-slug-kebab-case",
  "display_order": 10,
  "grammar_text": "<h2>Заголовок</h2><p>HTML-текст граматики...</p>",
  "words": [
    {
      "spanish": "hola",
      "pronunciation": "ОЛА",
      "ukrainian": "привіт",
      "example_es": "¡Hola! ¿Cómo estás?",
      "example_uk": "Привіт! Як справи?",
      "gender": null,
      "part_of_speech": "вигук"
    }
  ]
}
```

**Поля слів:**
| Поле | Обов'язкове | Опис |
|------|-------------|------|
| `spanish` | ✅ | Іспанське слово |
| `ukrainian` | ✅ | Переклад українською |
| `pronunciation` | — | Вимова великими: `ОЛА`, `усТЕД` |
| `example_es` | — | Приклад речення іспанською |
| `example_uk` | — | Переклад прикладу |
| `gender` | — | `"m"`, `"f"`, або `null` |
| `part_of_speech` | — | `"іменник"`, `"дієслово"`, `"прикметник"` тощо |

**`display_order`**: визначає порядок відображення на головній. Подивися існуючі файли і постав наступне число.

**`grammar_text`**: HTML-рядок. Підтримуються `<h2>`, `<h3>`, `<p>`, `<ul>`, `<li>`, `<table>`, `<strong>`, `<em>`. Рендериться через `@tailwindcss/typography`.

### Крок 2 — залити в базу даних

```bash
# Один файл
npx tsx scripts/seed-topic.ts data/topics/<slug>.json

# Або всі файли одразу
npm run seed
```

Скрипт ідемпотентний: можна запускати повторно — оновить існуючі записи, не задублює.

### Крок 3 — перевірити

Відкрий `http://localhost:3000` — тема з'явиться в списку.

## Як додати домашнє завдання (Homework)

### Структура файлу

Створи `data/homework/<id>.json`. Назва файлу = ID завдання (використовується в URL `/homework/<id>`).

```json
{
  "id": "lesson-06",
  "title": "Урок 6 — Назва уроку",
  "due_date": "2026-06-15",
  "audio": [
    { "label": "Аудіо 07", "src": "/audio/au_plus_1_07.mp3" }
  ],
  "exercises": [ ... ]
}
```

**Аудіо**: файли MP3 кладемо в `audio/` (кореневий каталог проекту), посилання `"/audio/<filename>.mp3"`. Next.js автоматично обслуговує файли з `audio/` як статичні.

**`due_date`**: формат `YYYY-MM-DD`. Відображається як "Сьогодні!", "Завтра", "3 дн." або "Минуло".

### Типи вправ

#### Спільні поля вправ

| Поле | Обов'язкове | Опис |
|------|-------------|------|
| `id` | ✅ | Унікальний ідентифікатор вправи (`"A"`, `"B"` тощо) |
| `label` | ✅ | Відображається на значку вправи |
| `instruction` | ✅ | Інструкція іспанською (або будь-якою мовою) |
| `instruction_uk` | — | Переклад інструкції українською. Якщо вказано — під інструкцією з'являється кнопка «Показати переклад» |
| `type` | ✅ | Тип вправи: `"fill-form"` або `"match-category"` |

#### `fill-form` — заповнити форму зі словника

Студент вибирає слова зі словникового банку і вставляє в порожні поля.

```json
{
  "id": "A",
  "label": "A",
  "instruction": "Прочитай та заповни форму.",
  "type": "fill-form",
  "word_bank": ["Barbara", "brasileño", "675312908"],
  "people": [
    {
      "nombre": "Paulo",
      "apellido": "De Souza",
      "correo": "paulo@gmail.com",
      "fields": [
        {
          "id": "p1-edad",
          "label": "Edad:",
          "answer": "27"
        },
        {
          "id": "p1-nac",
          "label": "Nacionalidad:",
          "answer": "brasileño",
          "given": false
        },
        {
          "id": "p1-prof",
          "label": "Profesión:",
          "answer": "estudiante",
          "given": true
        }
      ]
    }
  ]
}
```

- `given: true` — поле вже заповнене (відображається як статичний текст, студент не взаємодіє)
- `given: false` або відсутнє — порожнє поле для заповнення
- `id` полів має бути унікальним в межах всього завдання (`p1-edad`, `p2-nombre` тощо)
- `word_bank` — всі слова, з яких студент вибирає відповіді (включай навіть зайві слова для складності)

#### `match-category` — підібрати категорію

Студент призначає кожному питанню номер категорії.

```json
{
  "id": "B",
  "label": "B",
  "instruction": "Визнач, про що запитують.",
  "type": "match-category",
  "categories": [
    { "id": 1, "text": "la nacionalidad" },
    { "id": 2, "text": "el nombre" },
    { "id": 3, "text": "la edad" }
  ],
  "questions": [
    { "id": "q1", "text": "¿Cómo te llamas?",   "answer": 2 },
    { "id": "q2", "text": "¿Cuántos años tienes?", "answer": 3 },
    { "id": "q3", "text": "¿De dónde eres?",     "answer": 1 }
  ]
}
```

- `categories[].id` — число від 1, відображається як кнопка-цифра
- `questions[].answer` — число, що відповідає `categories[].id`
- `questions[].id` має бути унікальним

### Перевірка

Файл підхоплюється автоматично — перезапуск сервера не потрібен (Next.js читає файл при кожному запиті). Відкрий `http://localhost:3000/homework`.

## Довге повторення (`/dictionary/review`)

Щоденне повторення **всіх слів зі Словника** (`data/vocabulary/*.json`). Терміни — у `GLOSSARY.md`.
Вхід — кнопка «Повторення» з лічильником справа вгорі `/dictionary` (у нижньому меню вкладки немає; `/review` перенаправляє).

- Сторінка `/dictionary/review` (`app/dictionary/review/`) — як сторінка групи: прогрес дня, Flashcards / Learn / Blast поточної добірки, слова за оцінками (неоцінені не показуються), «Ще 10 слів», коли добірку оцінено.
  Порядок: спершу Flashcards оцінюють усю добірку, потім Learn і Blast тренують лише слова з «не знаю» й «вагався» (`practiceWords` у `core.ts`); до того вони закриті. Які слова тренувати, вирішує браузер — з урахуванням черги оцінок.
  - `flashcards` — `ReviewFlashcards.tsx`: із сортуванням свайп вправо «Знаю», вліво «Не знаю», кнопка «Вагався»; далі ще раз слова з «не знаю»/«вагався» (без запису); «Назад» скасовує оцінку. Без сортування — гортання, нічого не записується.
  - `learn` — `LearnMode` з окремим прогресом на добірку (`scope = review:<день>:<добірка>`, `reviewLearnScope`); на розклад не впливає.
  - `blast` — слова з «не знаю» й «вагався», один спільний рекорд (`REVIEW_BLAST` у `lib/blast`), на оцінки не впливає.
- `lib/review/core.ts` — усі правила, чистий код без БД (тести: `npm test`):
  інтервали «знаю» 14 → 30 → 60 → 120 днів; «вагався» — через 2 дні, наступне «знаю» повторює попередній інтервал; «не знаю» — завтра, з початку драбини;
  добірка 5 на повторення (борг → планові) + 5 нових випадкових;
  перевірка вписаного (наголоси/ñ/регістр не важливі, артикль можна не писати, неправильний артикль або одна опечатка — «вагався»);
  `scheduleDay` — розклад рахується від дня відповіді (оцінку могли поставити офлайн).
- `lib/review/store.ts` — таблиці `review_cards`, `review_batches`, `review_answers` (створюються автоматично при першому зверненні). У `review_answers.prev_card` — стан слова до оцінки, для скасування. Рахується перша оцінка слова в добірці.
- `lib/review/index.ts` — інтерфейс модуля: `getTodayReview`, `recordAnswer`, `undoAnswer`, `addBatch`, `checkInBatch`. API: `POST /api/review` з `action` (`answer` | `undo` | `more`).
- `lib/reviewOutbox.ts` — оцінки Flashcards ідуть через чергу в `localStorage` (`review-outbox`) і відправляються по порядку; без мережі чекають. Сторінки показують оцінки з урахуванням черги (`mergeAnswers`).
- Слово ідентифікується за іспанським написанням (`wordKey`): зміна написання в JSON = нове слово для розкладу.
- День рахується за Києвом. Збережена копія вчорашньої добірки без мережі показує «Немає інтернету» (`ReviewDayGuard`).

## Словник: сторінка групи та режими (`/dictionary`)

Набір (`data/vocabulary/<набір>.json`) ділиться на групи. Маршрути:

- `/dictionary/<набір>` — список груп і «Вивчити все», притиснуте до низу екрана над нижнім меню (`components/spanish/PinnedAboveNav.tsx`; висота меню — CSS-змінна `--bottom-nav-h` у `globals.css`); набір з однією групою одразу перенаправляє на групу.
- `/dictionary/<набір>/all` — псевдогрупа «Усі слова» (усі слова набору без повторів, `allWordsGroup` у `lib/vocabulary.ts`) — фінальний прохід після вивчення по частинах.
- `/dictionary/<набір>/<група>` — сторінка групи як у Quizlet: карусель карток, кнопки режимів, прогрес, список слів за статусом (`GroupClient.tsx`).
- `/dictionary/<набір>/<група>/flashcards` — флешкартки на весь екран (`FlashcardsMode.tsx`): картка фіксованого розміру, сортування «Знаю / Ще вчу» або просте гортання. Місце, де зупинився (колода, картка, оцінки раунду), зберігається в `localStorage` (`lib/flashcardProgress.ts`, ключ на групу; для Повторення — на добірку дня, старі стираються); «Почати спочатку» чи зміна перемішування/сортування його скидають.
- `/dictionary/<набір>/<група>/learn` — Learn (`LearnMode.tsx`): раунди до 7 питань, вибір із 4 перекладів → вписування іспанською.
- `/dictionary/<набір>/<група>/blast` — гра Blast (`BlastMode.tsx`): вгорі переклад, до 4 астероїдів з іспанськими словами групи; політ рахується в `requestAnimationFrame` і пишеться прямо в DOM. Пауза (кнопка, Esc/P, автоматично при схованій вкладці) зупиняє час, політ і музику й розмиває екран. Музика — `lib/blastMusic.ts`: синтезований Web Audio луп без аудіофайлів; мют повністю зупиняє аудіо (не лише гучність) і запам'ятовується в `localStorage` (`blast-music-muted`); вмикати звук треба з обробника кліку (вимога iOS).

### Blast (`lib/blast/`)

Механіка як у Quizlet Blast (бали відновлені з рахунку реальної гри: 5, 11, 18, 26, 35, 45, 56…; решта — зі спостережень):

- `core.ts` — правила, чистий код без БД (тести: `npm test`): на раунд 60 с; цілі рівнів 50, 75, 125, 200, 250, далі +50 (`goalFor`); раунд закінчується, щойно ціль набрано (`roundComplete`), бали раунду окремі, загальний рахунок — їх сума; не набрав ціль за 60 с — кінець гри. Влучання — 5 × множник серії (+0.2 за кожне влучання поспіль, стеля ×3); промах −2 (не нижче 0) і серія з нуля. До 4 астероїдів, слова йдуть по колу, підказка не повторюється двічі поспіль; слова з однаковим перекладом взаємозамінні.
- `store.ts` — таблиця `blast_scores (set_id, group_id, best_score, best_level)`: рекорд — одна найкраща гра (загальний рахунок) і рівень, до якого в ній дійшов. Рекорди з іншою версією правил (`RULES_VERSION` у `core.ts`, колонка `rules_version`) видаляються при міграції — змінюючи підрахунок, збільшуй версію.
- `index.ts` — `getBest`, `recordScore` (сервер перевіряє, що рахунок відповідає рівню: не менше `minScoreToReach`, не більше `maxScoreToEndAt`). API: `POST /api/blast` з `action: "score"`, `score`, `level`. На статус слів Blast не впливає.

Спільне для модулів: `lib/random.ts` (`shuffle`, `Rng`), `once()` у `lib/db.ts` для одноразового створення таблиць.

### Learn (`lib/learn/`)

- `core.ts` — усі правила, чистий код без БД (тести: `npm test`): етапи слова `new` → `learning` (правильний вибір) → `mastered` (правильно вписав); помилка чи «Не знаю» — назад у `new`; правильна відповідь етап не знижує. Раунд: спершу слова на вписування, потім нові на вибір (спершу ті, де помилився), перемішано. Хибні варіанти — із запасу 20: своя група → інші групи набору → інші набори. Вписане перевіряється як у Повторенні (одна опечатка чи артикль — зараховано з підказкою).
- `store.ts` — таблиця `learn_progress (scope, word_key, stage)` (створюється автоматично). Звичайні групи — `scope = ''`, етап на слово (`wordKey`), спільний для всіх груп; «Усі слова» — окремий `scope = 'all:<набір>'`, щоб фінальний прохід був справжнім.
- `index.ts` — інтерфейс: `getStages`, `recordAnswer`, `resetWords`, `learnMaterials`, `learnScope`, `newSeed`. API: `POST /api/learn` з `action` (`answer` | `reset`) і `scope`.
- Раунд і варіанти будуються з зерна, яке дає сервер (`seededRng`), — щоб сервер і браузер показали те саме питання.
- Статус слів на сторінці групи («Не вивчав / Ще вчу / Вивчено») веде тільки Learn. Learn груп і Повторення одне на одне не впливають (Learn усередині Повторення має свій прогрес на добірку).

Спільне: `components/spanish/SwipeFlipCard.tsx` (картка з анімаціями Quizlet; `fill` — фіксований розмір, `plain` — без оцінок, `stack` — колода під карткою), `components/spanish/WordNotes.tsx` (асоціація + приклад), `lib/flashcardSettings.ts` (налаштування флешкарток у `localStorage`, спільні для всіх груп), `lib/speak.ts` (озвучення — тільки на клік).

## Відмінювання (`/topics/conjugation-practice`)

Тема в «Теми» (БД: граматика + 40 інфінітивів) лише з двома вкладками: «Граматика» і «Відмінювання» (`components/spanish/Conjugation.tsx`). Карток і тесту в ній немає — слова вчимо в Словнику; вкладку «Вписати» теж прибрано, бо вона відмінює лише за правилом. Вкладку показує сторінка теми за slug (`CONJUGATION_TOPIC_SLUG` у `lib/conjugation/data.ts`).

- `data/conjugation/presente.json` — 40 дієслів (22 правильні, 18 неправильних): 6 форм presente і по одному реченню на особу (240) з українським перекладом; `alt` — інші допустимі порядки слів. Форми й речення записані явно, не обчислюються. Тема для БД — `data/topics/conjugation-practice.json` (граматика з таблицями; `npx tsx scripts/seed-topic.ts data/topics/conjugation-practice.json`).
- Пара «дієслово + особа»: спершу вписати форму (літери точно, одруківка — помилка; наголоси, ñ і регістр не важливі). Правильна форма — тонка смужка (`AutoBar`, як у «Вписати») заповнюється за `AUTO_ADVANCE_MS` (≈2 с), і речення відкривається саме, без кнопки й підпису; після помилки показується правильна форма й кнопка «Далі». Тоді скласти речення зі слів (без розділових знаків; зараховується основний чи будь-який запасний порядок): слово можна натиснути або перетягнути (`WordBuilder`, pointer-події — миша й палець): з низу в потрібне місце речення, у реченні на інше місце, з речення вниз — прибрати; чиста логіка місця вставки — `insertIndex`, `moveWord` у `core.ts`.
- `lib/conjugation/core.ts` — усі правила, чистий код без БД (тести: `npm test`, вони ж перевіряють дані: кожна форма є у своїх реченнях, правильні дієслова — за таблицею закінчень). Вкладка починається з екрана з кнопкою «Почати» («Продовжити», якщо є недопройдена сесія; без фільтрів). Сама вправа — на весь екран, як Flashcards і Learn (`fixed inset-0`, `useVisibleViewport`): угорі лише ✕ і лічильник, поле вводу й кнопки закріплені знизу над клавіатурою (`Frame` / `Body` / `Footer`). Сесія — 10 різних дієслів із 40, особа випадкова; після проходу — підсумок, «Ще раз помилки» (пари з помилкою у формі чи реченні) і «Ще 10» (дієслова щойно пройденої сесії беруться останніми).
- Прогрес — лише в `localStorage` (`lib/flashcardProgress.ts`, ключ `conjugation:presente`): недопройдену сесію продовжує з тієї ж пари; пройдену не показує знову — чекає «Почати». У БД і в розклад Повторення нічого не пишеться.
- Додаючи дієслово: блок у `data/conjugation/presente.json` (шість форм і шість речень, підмет у реченні явно) і слово в `data/topics/conjugation-practice.json`.

## Офлайн (застосунок на головному екрані iPhone)

Без інтернету працюють Flashcards і Blast усіх груп Словника і сьогоднішньої добірки Повторення (якщо її сьогодні вже відкривали з мережею); решта веде на `/offline` («Немає інтернету»). Learn офлайн не зберігається.

- `public/sw.js` — service worker: сторінки Словника — спершу мережа, без неї збережена копія; інші сторінки не зберігаються (без мережі — перехід на `/offline`); файли збірки `/_next/static/…` — спершу кеш. Реєструється лише в продакшн-збірці (`components/spanish/ServiceWorker.tsx`).
- `lib/offlineCache.ts` — копію (≈200 сторінок зі списку `/api/offline-urls`, `lib/offline.ts`, і файли, на які вони посилаються) качає **сама сторінка**, поки застосунок відкритий: фонова робота в service worker на iOS ненадійна. Раз на деплой — версія `NEXT_PUBLIC_APP_VERSION` з `next.config.ts` (коміт на Vercel). Нова копія качається в тимчасовий кеш і замінює стару лише повністю; після помилки сервера чи мережі — повтор не частіше ніж раз на годину.
- `lib/reviewOutbox.ts` — оцінки Повторення без мережі чекають у черзі (див. «Довге повторення»).
- `lib/blastOutbox.ts` — рекорд Blast без мережі (чи при 5xx) лягає в чергу в `localStorage` і відправляється, щойно з'явиться зв'язок; викидається лише відхилений сервером (4xx).
- Набори з однією групою в списку Словника посилаються одразу на групу (`setHref` у `lib/vocabulary.ts`): перенаправлену сторінку Safari з кешу не віддає.
- Додаючи нові режими чи сторінки для офлайну — додай їх у `offlineUrls()`.

## Важливі конвенції

- **Мова UI**: українська (всі написи, підказки, повідомлення про помилки)
- **Мова граматики**: українська пояснення + іспанські приклади
- **Server Components**: сторінки теми та головна — async server components, запити до БД напряму
- **Client Components**: все інтерактивне (флешкарти, вікторина, аудіо) — `"use client"`, стан у `useState`, прогрес зберігається через `fetch('/api/progress', ...)`
- **Homework стан**: прогрес вправ домашніх завдань зберігається в `localStorage` (ключ: `hw-<id>-<exerciseId>`)
- **Slug**: тільки малі літери, цифри, дефіс — `kebab-case`
- **Тема без слів** (`"words": []`) — урок лише з граматикою: вкладок «Картки» і «Тест», лічильника слів і смужки прогресу немає. Слова до уроку додаємо у Словник, а не в тему
- **Порядок тем**: на головній найновіша тема зверху — `created_at` DESC, потім `id` DESC (`display_order` у списку не використовується)
- **Частина мови в Словниках**: кожне слово в `data/vocabulary/*.json` **обов'язково** має `"part_of_speech"` — одне з `noun`, `verb`, `adjective`, `adverb`, `pronoun`, `preposition`, `conjunction`, `numeral`, `interjection`, `phrase` (список — `lib/partOfSpeech.ts`). Learn добирає хибні варіанти тієї ж частини мови (інакше правильну відповідь видно з форми слова). Не вгадуй за закінченням — став за змістом: `verb` — інфінітив (`hablar`, `levantarse`, `tener hambre`); `noun` — з артиклем (`el/la`) або назва дня/місяця; `adjective` — і форми `contento/a`; `preposition` — і звороти (`delante de`); `phrase` — вирази й речення, що не зводяться до однієї частини мови (`hace frío`, `¿Qué tiempo hace?`). Поле ставимо після `ukrainian`. `npm test` падає, якщо в новому наборі поле пропущене чи значення не зі списку, а також якщо «дієслово» не інфінітив або слово з артиклем не іменник
- **Словники** (`data/vocabulary/*.json`): у кожному файлі поле `"added_at"` (ISO-дата з часом, одразу після `description`). Сторінка `/dictionary` сортує за ним від нових до старих — новий набір завжди зверху. Додаючи набір, став поточну дату й час
- **Звукові асоціації** (`sound_association`): через **добре відоме** слово (українське чи англійське) + короткий образ зі значенням; для інтернаціональних слів — «те саме слово, що …». Не використовувати рідкісні слова (МАДРУГА, КАНЕЛЮРИ…), бо вони не допомагають запам'ятати

## Типові помилки

| Помилка | Причина | Рішення |
|---------|---------|---------|
| `DATABASE_URL` not set | Немає `.env.local` | Скопіюй `.env.local.example` → `.env.local`, встав рядок підключення |
| `notFound()` на сторінці теми | `slug` у URL не співпадає з БД | Перевір slug у JSON та запусти `npm run seed` |
| Домашнє завдання не відображається | Файл не в `data/homework/` або розширення не `.json` | Перевір шлях та ім'я файлу |
| Аудіо не грає | Файл не в `audio/` або неправильний `src` | `src` має бути `/audio/<filename>.mp3` |
